极简集成

只需几秒钟，即可在你的项目中运行

Step 1: 添加依赖 (settings.gradle) 
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        mavenCentral()
        maven { url 'https://jitpack.io' }
    }
}
Step 2: 引入组件 (build.gradle) 
dependencies {
    implementation 'com.github.mouren-h:PermissionDialog:1.0'
}
Step 3: 在 Activity 中调用 
import mr.x.permissiondialog.PermissionDialog;

// 1. 设置回调 (可选)
PermissionDialog.Async(new PermissionDialog.Cqd() {
    @Override
    public void djk(String result, String pd) {
        if ("true".equals(pd)) {
            // 权限已就绪
        }
    }
});

// 2. 启动检测并弹窗
PermissionDialog.qdjc(this);

// 3. 从设置页返回时刷新
@Override
protected void onResume() {
    super.onResume();
    PermissionDialog.jckq(this);
}
